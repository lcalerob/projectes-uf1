# YELMO — Rediseño conceptual

Proyecto frontend independiente inspirado en la estructura de una web de cine.

Archivos:
- index.html: estructura completa
- styles.css: diseño responsive
- script.js: filtros, selector de cine, sesiones, newsletter y mensajes demo

Para verlo:
1. Abre index.html con Chrome/Edge.
2. No necesita servidor ni instalación.
3. Los datos de películas y horarios de script.js son de demostración.

Nota: es un concepto de rediseño y no es una web oficial de Yelmo.
